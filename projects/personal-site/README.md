# Sachin Kumar — Personal Site

A standalone, responsive portfolio site built with HTML, CSS, vanilla JavaScript, and Express. It includes the cropped profile portrait, interactive terminal, theme switch, project details, contact form, and downloadable résumé.

**Live site:** https://sachin-kumar-portfolio-itv8.onrender.com/

## Run locally

```bash
npm install
npm start
```

Then open http://localhost:3000.

## Project files

- `server.js` — Express static server and health endpoint
- `public/index.html` — page content and structure
- `public/style.css` — responsive styles and themes
- `public/app.js` — terminal, theme, project details, and contact form interactions
- `public/images/sachin-portrait.jpg` — cropped profile portrait
- `public/files/Sachin-Kumar-Resume.pdf` — downloadable résumé
